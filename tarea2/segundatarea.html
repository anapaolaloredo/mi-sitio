Objetivos

  • Comprender los diferentes modelos de servicio en la nube (IaaS, PaaS, SaaS y FaaS).
  • Identificar las características clave de cada modelo de servicio.
  • Representar visualmente las diferencias y similitudes entre los modelos mediante un mapa conceptual.
  • Facilitar la toma de decisiones informadas sobre cuál modelo es más adecuado para diferentes necesidades empresariales.

Descripción del ejercicio

Crear un mapa conceptual comparativo. Para cada modelo de servicio (IaaS, PaaS, SaaS y FaaS), se identifican las características clave y se representan visualmente en el mapa conceptual. Esto incluye aspectos como la definición, ejemplos de proveedores y casos de uso típicos.
